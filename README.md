This combined semester project for Prg4AI and AI.
# AI-Based Old Photo Damage Detection and Restoration

## Project Description
This project uses Artificial Intelligence to detect damage
in old photographs and restore their quality.

## Main Objectives
- Detect scratches, dust, cracks, and stains.
- Restore damaged photographs.
- Display before-and-after results.

## Technologies
- Python
- OpenCV
- NumPy
- PyTorch
- Streamlit

## Project Modules
1. Image Preprocessing
2. Damage Detection
3. Image Restoration
4. Model Evaluation
5. User Interface
